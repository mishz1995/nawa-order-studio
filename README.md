# نوى — إدارة الطلبات

تطبيق عربي لإدارة طلبات المقاهي والمتاجر، مع لوحة سوبر أدمن، لوحة لكل متجر، شاشة QR، وبطاقة حالة للعميل بعد المسح.

## التشغيل المحلي

1. استخدم Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`، وضع كلمة مرور أدمن قوية وسرًا عشوائيًا لـ `SESSION_SECRET` بطول 32 خانة أو أكثر.
3. شغّل `npm ci` ثم `npm start`.
4. افتح `http://localhost:3000`.

تُحفظ قاعدة البيانات محليًا في `data/nawa.enc` مشفرة بـ AES-256-GCM. كلمات المرور مشتقة باستخدام scrypt. لا ترفع `.env` أو `data/` إلى Git.

## صلاحيات وتدفق الطلب

- الأدمن سوبر أدمن على جميع المتاجر: إدارة الحسابات وكلمات المرور، إعدادات المتجر، الأصناف، الطلبات وحالاتها، روابط Google Maps، التصميم والتفعيل والحذف.
- المتجر ينشئ الطلبات ويتابعها ويغيّر حالاتها. خيارات إنشاء الطلب إما اختيار أصناف قابلة للبحث أو إدخال يدوي حسب إعداد الأدمن.
- صفحة المتجر العامة لإنشاء الطلب غير متاحة. بعد إنشاء الطلب من لوحة المتجر، يظهر QR على شاشة المتجر؛ لا تُعرض بطاقة الحالة للعميل قبل مسح الرمز.
- صلاحيات مسح الطلبات المكتملة محدودة بحساب المتجر نفسه أو الأدمن على المتجر المحدد.

## فحوصات الحماية

- HTTPS إجباري في وضع الإنتاج مع HSTS، وجلسات `HttpOnly` و`SameSite` و`Secure`.
- رؤوس CSP و`X-Frame-Options` و`nosniff` وسياسة صلاحيات المتصفح.
- حماية CSRF عبر مطابقة Origin وSameSite، وتحديد معدل محاولات الدخول والطلبات.
- ملف البيانات المحلي مشفّر. في الاستضافة، تُخزّن لقطة قاعدة البيانات المشفرة نفسها في Upstash عبر HTTPS، ومفتاحها مشتق من `SESSION_SECRET`.
- لا يحتوي المستودع على ملف `.env` أو بيانات الدخول. حدّث بيانات الدخول التجريبية قبل النشر العام.

## إعداد استضافة مجانية

يوجد ملف `render.yaml` لخدمة Render المجانية. تحتاج أيضًا إلى قاعدة Upstash Redis مجانية، ثم تضع `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN` في إعدادات الخدمة. لا يبدأ وضع الإنتاج من دون مخزن دائم، حتى لا تضيع الطلبات عند إعادة تشغيل الخادم.

ستحتاج إلى ربط مستودع GitHub خاص بحساب Render وإدخال اسم المستخدم وكلمة المرور الأوليين للأدمن. رابط Render المجاني يستخدم TLS، لكنه قد ينام بعد عدم النشاط. مخزن Upstash يحدّه مستوى الاستخدام المجاني؛ راجع حدوده الحالية قبل الاستخدام التجاري.

## إشعارات الجاهزية

Web Push اختياري ويحتاج مفاتيح VAPID في إعدادات الاستضافة. الإشعارات لا تعمل على iPhone إلا من الموقع المضاف إلى الشاشة الرئيسية وعلى إصدار يدعم Web Push.
